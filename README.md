## 📖 Описание

Movie Library — это графическое приложение на Python с использованием библиотеки Tkinter для хранения и управления информацией о фильмах. Программа позволяет добавлять фильмы, фильтровать их по жанру и году, просматривать статистику, а также экспортировать данные в CSV.

## 🚀 Функциональность

- ✅ Добавление фильмов (название, жанр, год, рейтинг)
- ✅ Просмотр всех фильмов в таблице с визуальным рейтингом (⭐)
- ✅ Фильтрация фильмов по жанру (15 жанров)
- ✅ Фильтрация фильмов по году выпуска
- ✅ Удаление выбранных записей
- ✅ Подробная статистика (общая, по жанрам)
- ✅ Топ-5 лучших фильмов
- ✅ Экспорт данных в CSV файл
- ✅ Автоматическое сохранение в JSON
- ✅ Загрузка данных при запуске
- ✅ Валидация ввода (год, рейтинг 0-10)
